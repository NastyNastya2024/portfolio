Общее описание

Прототипирование на Tilda. Собран промо-лендинг Meta Morfeya: структура страниц, смысловые блоки, типографика и визуальный стиль, формы и сценарии заявок в рамках платформы Tilda. Такой подход дал быстрые итерации макета и выкладку готового сайта без отдельного бэкенда.

Создание онлайн-игры «Лила». Реализована браузерная версия трансформационной игры: поле 8×9, ход «змейкой», кубик, режим для одного игрока и для нескольких участников. Игра размещена на GitHub Pages, чтобы её можно было открыть бесплатно в браузере без установки.
