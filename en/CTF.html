General description

ClariTech is a specialized information system for modeling, analyzing and managing enterprise costs. The system is designed to build a transparent financial model of an organization, which reflects the sources of expenses, the rules for their distribution and the impact of costs on products, projects, services and divisions. ClariTech allows you to move from disparate calculations in tables to a single structured model based on cause-and-effect relationships.

ClariTech is based on a graph-based approach to financial modeling. The system supports loading data from external sources, automatic cost calculation, scenario and plan-to-fact analysis, as well as identifying the causes of deviations in financial indicators.

ClariTech is used as a management accounting and decision support tool. It is used by finance teams and management to improve cost transparency, measure performance, optimize costs and inform management decisions. The system can work both in the cloud format and in a corporate IT environment, complementing ERP and BI solutions, but not replacing them.

Project Description

UI/UX platform redesign

Stage 1. Before redesign (It was) +

The initial interface of the platform was formed organically and over time acquired a large number of repetitive and inconsistent patterns, which significantly complicated the work of users.

  • There was no clear interface structure: navigation between models was carried out through the top panel without a logical division into sections.
  • Management of total TCO, direct and unallocated costs was moved to the top menu, without obvious connection with the context of the current model.
  • Working with model nodes was difficult: there was no single interface for managing connections, which made it difficult for the user to understand the structure and logic of the model.
  • The process of inserting parameters into formulas was unintuitive and required unnecessary steps.
  • The node's controls were distributed across several interface zones: the sidebar, the bottom panel with drop-down lists in the center of the screen, and the side menu.
  • The nodes were controlled through many additional buttons, the icons of which were not cognitively obvious and required training.
  • Despite the presence of useful functions (change of language, editing mode for the administrator, quick exit button), they were not integrated into a single logical system.

As a result, the interface looked cluttered, difficult to master, and poorly scalable.

Stage 2. After redesign (Now) +

During the redesign, a comprehensive revision of the UX architecture was carried out in order to remove repetitive patterns, simplify navigation and make working with models more transparent.

  • At customer request, a menu button has been added at the top of the screen to switch between models.
  • The main menu is placed in the top navigation and is structured.
  • New logical sections have been added (for example, Directories and Settings), which has increased the integrity of the interface.
  • Key service functions have been preserved and logically integrated: language change, editing mode for the administrator and a quick exit button.
  • The grid for constructing the model has been removed - the interface has become visually lighter and less congested.
  • A new form for editing nodes has been developed.
  • All actions and buttons are grouped into single semantic blocks, duplication has been eliminated.
  • A compact menu has been created for the most important and frequently used actions.
  • Added a button to quickly add elements to the screen.
  • Node management was placed in a separate “node passport”, which simplified navigation between nodes and made the configuration of each node more understandable and isolated.
  • The ability to record a solution and demonstrate it to other users has been implemented.

As a result, the platform received a cleaner, more logical and scalable UX architecture, the cognitive barrier to entry was lowered, and working with models and nodes became much faster and more transparent.

Expanding the functionality of the platform: developing new sections and updating UI components +

As part of the platform redesign, a comprehensive redesign of the UI kit was carried out in order to unify the visual components and improve the user experience. All interface elements have been redesigned taking into account modern design principles and accessibility requirements.

In parallel with the update of existing components, the development of a significant number of new functional sections that were previously absent in the system was carried out. Among the created modules, sections such as “Reports” and “Directories” were introduced, which expanded the capabilities of the platform and improved the navigation structure.

The “Reports” section provides users with the ability to generate and export analytical data, visualize key indicators and generate documents for further use. The “Reference Books” section provides centralized access to reference information, data management and setting up system parameters.

All new sections were integrated into the overall platform architecture using an updated UI kit, which ensured visual consistency and uniformity of the interface at all levels of the system.
