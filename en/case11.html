Marketplace of flowers

Product design: buyer and seller in one ecosystem

Project Description

A single UI kit and visual design for two mobile applications

General description

The project is a flower marketplace divided into two roles:buyerAndsalesman. The work covers the full cycle of interface design: from splash screens and key flows to search states, catalog and communications.

PreparedUI kit- a library of visual solutions that links both applications: general layout principles, card and button components, navigation and illustrative style with 3D characters. For the buyer - a light pink and white palette and display scenarios; for the seller - a separate green thread with notification and chat screens, preserving MarketPlace brand recognition.

The result is a consistent ecosystem: two applications look like parts of one product, but are clearly separated by user tasks.

Buyer

Categories, seasonal banners, search and product cards; chat with the store in a single visual key.

Salesman

Login to the seller role, list of requests and chats; a green palette and a separate hero without breaking the brand.
